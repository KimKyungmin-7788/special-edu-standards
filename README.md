# 여기여기 모여라! 관련 성취기준

수업 주제나 앱 설명을 한 문장으로 적으면, 2022 개정 특수교육 기본 교육과정 성취기준 688개 중 연관된 것을 학교급·교과별로 모아 주는 교사용 도구입니다.

- 정적 사이트(빌드 없음). 검색은 브라우저 안에서만 처리하며 서버·API 호출이 없습니다.
- 데이터·엔진 원본은 별도 작업 폴더(standards-finder)에서 생성합니다. 이 저장소의 `standards.min.json`, `synonyms.json`, `search.js`는 그 결과물입니다.
- 성취기준 원문: 교육부 고시 제2022-34호 [별책 3] 특수교육 기본 교육과정
- 검색어 일부: 국립특수교육원(2023) 교과별 기본 교육과정 평가 자료 (해설·성취수준 전문은 싣지 않음)
- 운영: 김경민 · 개인정보처리방침 `/privacy` · 이용약관 `/terms`
